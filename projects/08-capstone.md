# A tiny production-minded platform

**Advanced · local or one paid cloud sandbox**

Combine a simple service with repeatable delivery, observable behavior and recovery evidence.

## Build

- Define the user, workload and cost/reliability constraints.
- Use infrastructure/configuration as code and a CI pipeline.
- Document identity, secrets, data flow and supply-chain choices.
- Keep the app small enough that you can explain every component.

## Demonstrate

- A second person can follow the clean setup guide.
- A bad deployment can be rolled back and sample data restored.
- A simulated incident produces a usable timeline and an actionable follow-up.

## Deliver

A portfolio repository with a diagram, ADR, cost estimate, runbook, incident review and a five-minute demo.

## Clean up

Document teardown of each component; verify retained storage and external services separately.

## Explain this tradeoff

Which complexity would you remove if the traffic and team were both ten times smaller?
