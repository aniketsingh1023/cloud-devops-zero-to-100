# Security

This is a learning-resource collection with a small local HTTP lab. The lab is a development exercise and is not supported as an internet-facing production service. Linked software has its own maintenance, security policy and license.

Do not publish live credentials, personal data or exploit details that affect a third party in an issue. For a sensitive vulnerability in this repository, use GitHub’s private vulnerability reporting option if enabled, or GitHub’s reporting tools. For an upstream issue, follow that project’s security policy.

For an exposed credential, revoke or rotate it with the issuing service before attempting repository cleanup. Removing it from a file does not remove it from Git history or invalidate it.

Ordinary broken links, inaccurate descriptions and non-sensitive lab bugs can be reported as normal issues.
