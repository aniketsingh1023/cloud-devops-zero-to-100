# From my GitHub stars

Selected from [aniketsingh1023’s public starred repositories](https://github.com/aniketsingh1023?tab=stars), reviewed November 3, 2026. **62 public stars reviewed; 22 relevant repositories selected.** This is a curated snapshot; later changes to the star list do not automatically change this page.

The selections are included in the main resource catalog with an original explanation, access notes and an exercise. README and repository metadata were reviewed for relevance; examples have not all been deployed or security-audited. Stars are a discovery signal, not a guarantee of correctness.

## Start with these five

1. [DevOps Cheatsheet Collection](https://github.com/NotHarshhaa/devops-cheatsheet): use as a command refresher after learning a concept.
2. [TechiesCamp DevOps Projects](https://github.com/techiescamp/devops-projects): choose one scoped build with cost and cleanup planning.
3. [Terraform with AWS](https://github.com/piyushsachdeva/Terraform-Full-Course-Aws) or [Terraform with Azure](https://github.com/piyushsachdeva/Terraform-Full-Course-Azure): follow the provider you chose.
4. [Kubernetes Kickstarter](https://github.com/LondheShubham153/kubestarter): apply the basic objects in a local cluster.
5. [Awesome System Design Resources](https://github.com/ashishps1/awesome-system-design-resources): connect the terminology to design decisions.

## How the selections fit the roadmap

Use the cheatsheets and interview questions for review, not as a substitute for building. The Terraform courses fit days 51–60; kubestarter and the Kubernetes tools fit days 61–70. Litmus is an advanced follow-up to the local game day. The EKS/GKE projects require cloud-specific cost and identity review. AI/MLOps stays optional after the core path.

Some repositories have older commands, account-specific examples, external promotions or uneven setup/cleanup coverage. Check current primary documentation before running them and replace example credentials/account values with your own scoped configuration.
